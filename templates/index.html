How it works

Resize

Your image is resized to 224×224 pixels to match the model's input shape.

Inference

A trained convolutional neural network runs a forward pass on the scan.

Classify

Returns a class: Normal or Tumor, shown instantly above.

Ensure you have run training (or pulled the model via DVC) so that artifacts/training/model.h5 exists before using Predict.
